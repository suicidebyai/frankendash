# Roadmap

> The evolution path from planning workspace to complete AI engineering platform.

---

# Development Philosophy

Frankengine will be built incrementally.

Each phase creates a usable foundation for the next.

The priority is not building the most features.

The priority is building the correct foundation.

---

# Phase 1: Foundation

## Goal

Create the core repository structure and architectural foundation.

## Deliverables

- Repository setup
- Canonical documentation
- Engineering standards
- Project structure
- Development workflow
- Technology decisions

## Status

Documentation foundation.

---

# Phase 2: Knowledge Engine

## Goal

Create the persistent memory layer.

## Deliverables

- SQLite database
- Database schema
- Knowledge Object system
- Relationships
- Version history
- Search
- Tagging
- Metadata system

## Outcome

Frankengine can store and retrieve structured engineering knowledge.

---

# Phase 3: Planner Engine

## Goal

Transform ideas into structured engineering plans.

## Deliverables

- Prompt pipeline system
- AI provider abstraction
- Blueprint generation
- Requirements generation
- Architecture generation
- Roadmap generation
- Risk analysis
- Knowledge Object extraction

## Outcome

Frankengine can convert ideas into reusable engineering artifacts.

---

# Phase 4: Desktop Application

## Goal

Create the user-facing workspace.

## Deliverables

- Electron shell
- React interface
- Project dashboard
- Blueprint editor
- Knowledge browser
- Search interface
- Settings system

## Outcome

Users can interact with Frankengine as a complete application.

---

# Phase 5: Automation Engine

## Goal

Move from assistance to workflows.

## Deliverables

- Automated pipelines
- Task generation
- Agent workflows
- Approval checkpoints
- Background processing
- Event system

## Outcome

Frankengine can coordinate complex engineering processes.

---

# Phase 6: Plugin Ecosystem

## Goal

Make Frankengine extensible.

## Deliverables

- Plugin SDK
- External integrations
- GitHub integration
- Custom AI providers
- Custom workflows
- Community extensions

## Outcome

Frankengine becomes a platform.

---

# Future Integrations

Potential integrations:

- GitHub
- Local development environments
- Cloud storage
- Local language models
- Documentation systems
- Project management tools

---

# Current Priority

The immediate focus is:

1. Complete documentation foundation
2. Define database schema
3. Build Knowledge Engine
4. Create first working Planner pipeline
5. Connect the desktop interface

---

# Guiding Principle

Build the memory first.

Build the intelligence second.

Build the interface third.

A beautiful interface without a strong knowledge foundation is just a fancy notebook.

Frankengine's value comes from what it remembers.
