# Parking Lot

## Purpose

The Parking Lot is Frankengine's internal scratchpad.

It exists to capture valuable ideas without allowing them to expand the current project scope.

Items stored here must not influence the active blueprint, architecture, implementation plan, or requirements unless explicitly promoted.

---

## Allowed

Future enhancements

Potential optimizations

Technical debt

Architecture concerns

Interesting observations

Questions for later

Possible plugins

Ideas outside the current milestone

---

## Not Allowed

Approved requirements

Accepted decisions

Current implementation details

Canonical documentation

Completed work

---

## Promotion Rules

An item may leave the Parking Lot only when:

- The user explicitly requests it.
- A project milestone includes it.
- An accepted decision promotes it.

Otherwise it remains parked.

---

## Example

Idea:

Support mobile applications.

Status:

Parked.

Reason:

Desktop-first MVP.

Review:

After Desktop v1.

---

The Parking Lot exists to preserve ideas without creating scope creep.
